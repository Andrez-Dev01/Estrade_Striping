## Development Strategy

The original production website will remain untouched while Estrada 2.0
is developed on a separate branch.

### Branch Structure

`master`
→ Current production website

`estrada-2.0-development`
→ Estrada 2.0 development

Production deployment will not be changed until the new application has
been tested, reviewed, and approved for launch.

## Engineering Principles

1. Build from actual client requirements.
2. Do not add technology solely for resume keywords.
3. Prefer simple architecture when complexity is unnecessary.
4. Preserve the working production system during development.
5. Test before production deployment.
6. Document engineering decisions.
7. Minimize recurring infrastructure costs.
8. Treat the application as a real production system.
